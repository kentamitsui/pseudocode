# pseudocode

##　このリポジトリの目的

1. 疑似コードを通して、自分の頭で考え手を動かして良いコードを書けるようになること
2. 文法の見直し、組み込み関数の使い方を地道に習得すること
3. 簡単な問題から徐々に難しい内容に取り組むことで、思考力と試行錯誤する力をつけること
4. 将来のコーディングテストに備えること

## 構成

```text
練習問題/1-5/   … 問題文（擬似コード）と各言語の解答
メモ/           … 文法・標準ライブラリなどのメモ
```

## 進め方

1問あたり、次の順で進める。

1. 自然な日本語で手順を書く
2. 構造化擬似コードにする（もし／繰り返す／代入＋インデント）
3. 実装する（対象ファイルの言語で具体化）
4. 実行して確認し、コミットする

完成コードの丸写しだけをコミットしない。擬似コードと対応が分かる状態で残す。

## ファイル命名

| 種類               | 例                                                      |
| ------------------ | ------------------------------------------------------- |
| 問題・擬似コード   | `日本語擬似コードで学ぶ…問題集.md`                      |
| 解答（多くの言語） | `問題N：タイトル.py` / `.c` / `.ts`                     |
| Java               | クラス名＝ファイル名（英数字）。例: `LinearSearch.java` |

同じ問題を複数言語で書く場合は、拡張子だけ変えて並べる。

## 実行方法

リポジトリ直下、または各ファイルのあるディレクトリで実行する。

```text
Python:  python 問題N：….py
C:       cc -o a.out 問題N：….c && ./a.out
TypeScript: tsx 問題N：….ts
Java:    javac LinearSearch.java && java LinearSearch
```

Cursor / VS Code では Code Runner でも可（TypeScript は `tsx` を使う）。

## 進捗の残し方

- 行動量の主記録は **Git のコミット履歴** とする
- コミットメッセージ例: `problem2: linear search (ts)` / `problem1: count items (c)`
- 日付ごとのメモが必要なら、別途 `進捗.md` に「日付 / 問題 / 言語」を1行で追記する

## 置かないもの

- 業務コード・個人情報・社内情報
- 提出用・機密の答案
- ビルド成果物（例: `*.class`, `a.out`）※必要なら `.gitignore` に追加
